# Theme fonts

Bundled so the themes look the same offline. Latin subsets in WOFF2, from Google Fonts, declared in `theme-fonts.css`. All are under the SIL Open Font License 1.1 (`OFL.txt`).

| Space Grotesk | Block, Graphite | SIL OFL 1.1 |
| Archivo Black | Block | SIL OFL 1.1 |
| VT323 | Terminal | SIL OFL 1.1 |
| Orbitron | Neon | SIL OFL 1.1 |
| Rajdhani | Neon, Overclock | SIL OFL 1.1 |
| IBM Plex Mono | Terminal | SIL OFL 1.1 |
| Press Start 2P | Arcade | SIL OFL 1.1 |
| Silkscreen | Arcade | SIL OFL 1.1 |
| Nunito | Nordic | SIL OFL 1.1 |
| Young Serif | Groovy | SIL OFL 1.1 |
| Fredoka | Bubblegum | SIL OFL 1.1 |
| Saira Semi Condensed | Console, the default | SIL OFL 1.1 |

Watercolour uses Sitka Banner and Sitka Text, which come with Windows 10 and 11, so nothing is bundled for it (Georgia is the fallback).

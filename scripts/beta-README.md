# Sleekmeeter test versions

Test versions (betas) of [Sleekmeeter](https://github.com/minimalhandle/SleekMeeter), a modern face for Voicemeeter. They have new features before everyone else, and may have more bugs.

**Only for people who want to test.** If you just want Sleekmeeter, use the [normal releases](https://github.com/minimalhandle/SleekMeeter/releases).

## How to get them

1. Install the newest test version from [Releases](../../releases) once (run the `-setup.exe`; your settings are kept).
2. In Sleekmeeter, turn on **Settings → Updates → Also offer test versions**.

From then on, new test versions appear as **Update to …** in Sleekmeeter's header. Turn the setting off to go back to full releases from the next one onwards.

Report problems on the [main project's issues](https://github.com/minimalhandle/SleekMeeter/issues).
